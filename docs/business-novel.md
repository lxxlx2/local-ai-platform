# BUSINESS_B — Novel factory architecture

GitHub Canon is the source of truth for `归灯记` and `还修什么仙`; a chat session is not durable memory.

`Task → Canon/RAG retrieval → Planning → Draft → Canon review → Revision → Human/Chief Editor review → Git commit → GitHub`.

V1 local-model roles are ordinary planning, drafting, organization, and preliminary review. Critical chapters and Canon decisions retain higher-level and human review. Existing repositories are not modified by infrastructure deployment.
