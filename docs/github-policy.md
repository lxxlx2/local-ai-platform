# GitHub policy

Git contains code, Canon, approved prompts, configurations without secrets, validation rules, release manifests, approved final assets, and curated reports. It does not contain model weights, MLX/Hugging Face caches, runtime state, raw logs, embedding databases, original livestream recordings, temporary media, discarded generations, `.env`, cookies, tokens, or private keys.

Existing business repositories remain read-only for V1. No bulk moves, commits, pushes, resets, cleans, restores, or checkouts are permitted. `~/Projects/` is future topology only; no migration occurred in V1.
