# Model Quality Gap

Qwen3.6 is the local FAST chat candidate: strong enough for validated local chat and context work, but not a universal model. Its autonomous coding-agent acceptance failed, so Coding remains NO.

| Gap | Primary cause | Correct response |
|---|---|---|
| Basic general answers | model and UX limits | model evaluation + concise intent contract |
| Product capability errors | missing registry | deterministic role-scoped capability text |
| Current information | missing tool | approved search workflow |
| Image understanding | missing model | future vision provider |
| Coding reliability | missing validated model | keep Qwen Coding=NO |
| Semantic recall | missing retrieval | future embedding/RAG |

Top five next improvements: validated coding/review model; embedding/RAG; controlled file/PDF pipeline; approved research workflow; vision model. This is a roadmap, not authorization to download models.
