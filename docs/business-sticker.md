# BUSINESS_D — Digital sticker factory architecture

Platforms: LINE Creators Market and WeChat sticker platform, with future extensibility.

`Market Research → Trend Analysis → Concept → Character Canon → Sticker Script → Prompt → Generate candidates → Technical/consistency/copyright QA → Platform validation → Package → Human Approval → Upload → Sales analytics → iteration`.

The governing rule is **REFERENCE WITHOUT COPYING**. Analyse themes, use cases, complexity, text ratio and package patterns; do not copy characters, phrases, trademarks, people, media, game, film, anime, or artist-identifying style.

Each character requires a Canon, STYLE_ANCHOR, variable/forbidden variations, and ORIGINALITY_RECORD. Any image model needs a recorded source, revision, licence and commercial-use status before production. V1 downloads no image model and performs no publication.
